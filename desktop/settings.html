Desktop performance and device permissions. Preferences stay on this PC.

Hardware AccelerationUse the GPU for rendering. Turning it off switches to software rendering. Restart required.
CPU BoostRaises VOX process scheduling priority to High. Does not overclock the CPU; may reduce responsiveness of other apps.
Low Latency ProfileReduces background renderer throttling and visual overhead. May use more CPU and battery.
Disable Animation EffectsTurns off interface transitions and animations.
MicrophoneAllow VOX to request microphone access for calls.
CameraAllow VOX to request camera access for calls.
Restart VOX to apply hardware acceleration or low latency changes. Your preferences are already saved.

Windows privacy controls remain authoritative. Screen sharing is selected when you start a share from VOX. GPU acceleration can vary by graphics driver. CPU Boost changes Windows process priority only; it does not change CPU clock speed.
